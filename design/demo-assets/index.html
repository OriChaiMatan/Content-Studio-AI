Product Constraints for Claude Design

Podcast label: Always "Podcast" — never "Podcast Script", "Audio", "Episode Script" or any audio-implying label.
No audio UI: No waveform, no play button, no audio player, no recording mic, no headphone icon. The Podcast output is a written narrative document.
LumAI is the engine: The reasoning and content is attributed to LumAI, not ChatGPT, OpenAI, or any external model branding.
Visual button scope: The "Visual" action button in the Review screen appears only on LinkedIn and Facebook tabs — not Newsletter or Podcast.
Demo pacing: The full product flow (Pipeline → Review → Visual) should teach itself in 35–45 seconds with no narration.
No annotation overlays: No highlight boxes, callout bubbles, tooltip arrows, or screenshot callouts inside the demo screens. Let the UI speak.
Dark premium only: Background #0D1121, primary blue #4D82E8 on dark, Inter font, Noto Serif for draft titles.
Completion state matters: The Library screen should feel like the payoff — established authority, not work in progress.
